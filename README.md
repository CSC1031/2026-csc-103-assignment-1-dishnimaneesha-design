Student Mark Analyzer

A simple C program that calculates:
Total Marks
Average Marks
Grade
Pass/Fail Status
Highest Subject Mark

Grade System
Average	Grade
80 - 100	A
70 - 79  	B
60 - 69	    C
50 - 59	    D
Below 50	F

Pass Rule
A student passes only if all subjects have marks of 40 or above.
